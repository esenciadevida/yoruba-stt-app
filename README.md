# 🎙️ BÁMI-SỌ̀RỌ̀ - Yoruba Speech-to-Text

High-accuracy Yoruba language speech recognition using W2V-BERT model.

## Features
- 🎤 Real-time speech recording (up to 60 seconds)
- 🎵 Complete tone mark restoration
- 🔐 User authentication
- 📜 History tracking
- 💾 Cloud save
